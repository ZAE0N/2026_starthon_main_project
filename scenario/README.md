# 테스트용 계약서

판정이 맞는지 확인하는 데 쓰는 표준근로계약서(단시간근로자용) 4종입니다.

**등장하는 사람·업체·주소는 전부 가상입니다.** 실제 계약서가 아니므로 그대로 올려도 됩니다.
실제 계약서 사진은 여기 두지 마세요. `samples/` 또는 `private/` 에 둡니다 (둘 다 `.gitignore`).

| `시나리오2_근로시간초과.pdf` | 주 6일 × 10시간 = 주 60시간, 10시간 근무에 휴게 30분 | **근로시간·휴게시간 = 위법소지** |
| `시나리오3_야간휴일수당미지급.pdf` | 야간 8시간 근무에 휴게 30분 | **휴게시간 = 위법소지** |
| `시나리오4_정상계약서.pdf` | 전부 적법 | **위법소지 0건** |

## 시나리오 4가 가장 중요합니다

**정상 계약서를 정상이라고 말하지 못하면 앱을 못 씁니다.** 없는 위법을 만들어내면
사용자가 그걸 믿고 사장님에게 따지게 됩니다. 모델을 바꿀 때 이 파일로 꼭 확인하세요.

실제로 `gpt-5.4-mini` 는 시나리오 3에서 **위약금 조항이 아예 없는데 위법소지**라고 했습니다.
그래서 쓰지 않습니다. 근거는 `server/run_local.md` 의 모델 비교표에 있습니다.

## 시나리오 3의 한계 — 알고 있어야 합니다

파일 이름은 "야간휴일수당미지급" 인데, **앱은 그 위법을 판정하지 못합니다.**

이 계약서의 진짜 문제는 특약입니다.

> 야간근로 및 휴일근로에 대해서도 위와 동일한 시급을 적용하며, 별도의 가산임금은 지급하지 않는다.

근로기준법 **제56조**(야간·휴일 각 50% 가산) 위반인데, `laws.json` 의 8개 항목에
제56조가 없습니다. 앱은 휴게시간 위반만 짚습니다.

항목을 9개로 늘리면 `types/index.ts`·서버 스키마·화면 문구가 같이 바뀌어야 해서
이번 범위에서 제외했습니다. `PROGRESS.md` 의 "개선 방향" 에 넣어뒀습니다.

**빠진 시나리오: 수습 감액.** 앱이 가장 공들인 판정(단순노무 직종은 1년 이상
계약이어도 감액 불가 — 최저임금법 제5조 제2항 단서)을 보여줄 계약서가 없습니다.
여유가 있으면 이런 계약서를 하나 추가하면 좋습니다.

```
업무의 내용 : 주방 보조 및 식기 세척
계약기간   : 2026.3.1 ~ 2027.2.28 (1년)
임금       : 시급 10,320원
특약       : 수습기간 3개월간 시급의 90%(9,288원)를 지급한다.
```

1년 계약 + 수습 3개월 + 90% 라 적법해 보이지만, 주방보조는 단순노무라 감액 자체가
불가능해서 위법입니다. **사람도 헷갈리는 것을 앱이 잡아내는** 좋은 시연 사례가 됩니다.

## 쓰는 방법

앱은 사진(JPEG)을 받습니다. PDF 를 그대로 넣을 수 없습니다.

- **인쇄해서 폰으로 촬영** — 가장 좋습니다. 조명·기울기·EXIF 회전까지 같이 검증됩니다
- 급하면 PDF 를 이미지로 변환해 갤러리에 넣고 "갤러리에서 고르기" 로 선택

앱 없이 서버만 시험하려면:

```bash
python server/check.py <이미지파일> \
  --url https://smpsws.shop/albacheck --token <APP_TOKEN>
```
